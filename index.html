Cloudscan

Eenmalig koppelen

  1. Maak een fine-grained token aan.
  2. Repository access: Only select repositories → innerlink-cloudscan.
  3. Permissions → Repository: Actions: Read and write en Contents: Read-only.
  4. Plak de token hieronder. Hij blijft alleen op dit apparaat.

Nieuwe scan

Een scan duurt meestal 4–6 minuten. Je mag deze pagina sluiten; je ziet de voortgang terug als je hem weer opent.
